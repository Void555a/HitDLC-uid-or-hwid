# HitDLC — реестр ключей и ПК

Этот репозиторий — база приглашений HitDLC. В нём нет самих ключей,
только их SHA-256 хеши, поэтому выкладывать его публично безопасно.

```
keys/<sha256>.json   — один файл на invite-ключ
hwid/<HWID>.json     — один файл на активированный ПК
pending/             — копии файлов, которые лоадер готовит к загрузке
```

Всего ключей: **100**.

## Как загрузить файлы на GitHub

1. Открой репозиторий в браузере.
2. **Add file → Upload files**.
3. Перетащи папку `keys` целиком (или все `.json` из неё).
4. Внизу нажми **Commit changes**.

Файлы `hwid/*.json` загружай так же, когда лоадер создаст их
на рабочем столе (после активации без GitHub-токена).

**Не переименовывай файлы** — имя файла и есть идентификатор ключа или ПК.

## Формат файла ключа

```json
{
  "key": "<sha256>",
  "hwid": "XXXX-XXXX-XXXX-XXXX",
  "nickname": "Player",
  "status": "active",
  "created": "2026-01-01T00:00:00Z",
  "activated": "2026-01-01T00:00:00Z",
  "app": "HitDLC 1.1"
}
```

- Пустой `hwid` = ключ ещё не использован.
- Другой `hwid` = ключ уже привязан к другому ПК, активация будет отклонена.
- `status": "revoked"` или `"blocked"` = ключ заблокирован вручную.
