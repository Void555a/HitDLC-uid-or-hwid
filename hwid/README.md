# hwid

Один `.json` на активированный ПК.
Имя файла = HWID вида `XXXX-XXXX-XXXX-XXXX`.

Файл создаётся лоадером на рабочем столе (папка `pending`/`hwid`)
и загружается сюда вручную, если в сборке нет GitHub-токена.

Если удалить файл ПК, тот же ключ сможет активироваться на другом железе
(полезно при замене компьютера).
